# Cathey's Lawn Care Website

Premium dark luxury website rebuild for Cathey's Lawn Care, Austin TX.

## Features
- Conversion-optimized landing page
- Lead booking form with Netlify Functions backend
- Admin dashboard for lead management
- Netlify Blobs for serverless storage
- Fully responsive design
- SEO optimized with Schema.org markup

## Deployment
1. Push to GitHub
2. Connect repo to Netlify
3. Set environment variables in Netlify dashboard:
   - `ADMIN_PASSWORD` - Admin panel password
   - `NOTIFICATION_EMAIL` - Email for lead notifications
   - `BUSINESS_NAME` - Cathey's Lawn Care
   - `SITE_URL` - https://cathys-lawn-care.netlify.app

## Admin Access
Navigate to `/admin` and enter the admin password.
